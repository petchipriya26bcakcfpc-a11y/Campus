# Campus



### Campus App 

### Project Overview
The Campus App helps students access college information, class schedules, events, and announcements easily in one place.

### Objective
* To provide college information easily.
* To help students check timetables and events.
* To improve communication between students and college.

### Design Highlights
* Simple and user-friendly interface.
* Attractive colours and icons.
* Easy navigation between pages.
* Clean layout with readable text.

### Features
* Student Login
* Home Dashboard
* Class Timetable
* College Events
* Announcements
* Student Profile
